## Proyectos

### Archivo Cofrade Córdoba (privado, en desarrollo)
Archivo digital de la Semana Santa de Córdoba que cataloga material cofrade (boletines, carteles, itinerarios, publicaciones, fotografías, estampas…) y las entidades que lo producen (hermandades, asociaciones, bandas, medios). Además, lleva el seguimiento de una colección personal: piezas en colección, buscadas o duplicadas.
- **Stack del front:** Next.js 16 (App Router), React 19, TypeScript strict, Tailwind CSS v4, desplegado en Vercel.
- **Backend:** NextJS, Prisma, PostgreSQL y API GraphQL. Archivos en AWS S3.
- **Catálogo con filtros facetados:** tipo de documento → subtipo, tipo de entidad → entidad, etiquetas, año o rango de años, estado de colección y efemérides. Todos los filtros son multiselección y el estado se guarda en la URL, así que cualquier búsqueda se puede compartir. Vista en cuadrícula o en lista, con orden y paginación.
- **Modelo de datos relacional:** piezas, entidades, series de publicación, etiquetas, copias y relaciones secundarias entre piezas y entidades. Consumido desde server components con peticiones en paralelo.
- **Panel de administración:** login OAuth, sesión JWT y formularios con server actions.
- **Visor de PDF** con miniaturas generadas con pdfjs-dist.
- **Sistema de diseño propio:** tema oscuro con tokens en Tailwind, tipografía editorial y componentes reutilizables.
- **Refactor del front por bloques**, con convenciones unificadas, commits limpios y el lint y el build revisados después de cada bloque.
- **En desarrollo:** una enciclopedia interna, al estilo de Wikipedia, con cientos de miles de líneas de contenido documentado con citas a fuentes y enlazado con las entidades y piezas del catálogo.
